# TPMP-lab2-task3: Работа со структурами данных (AIRPLANE2)

## Overview
Программа для работы с данными об авиарейсах. Реализует структуру **AIRPLANE2** и функции для анализа информации о рейсах:
* Ввод данных о рейсах с клавиатуры (не менее 12 записей)
* Поиск рейса с максимальной скоростью
* Вычисление средней скорости для определенной марки самолета

## Использование

1.  **Сборка проекта:**
    ```bash
    make
    ```

2.  **Запуск программы:**
    ```bash
    make run
    ```
    или
    ```bash
    ./bin/airplane_program
    ```

3.  **Очистка проекта:**
    ```bash
    make clean
    ```
